## 4. Onsets, en_basic_raw.wav (--raw) vs en_basic.wav (mastered), measured with out/onsets.py
Method: 5 ms RMS frames, onset = first frame within 30 dB of the file peak after >=60 ms of quiet; table = silence before onset (ms), first 10 ms level, level 50-100 ms later, delta. Crude: it also catches pauses inside sentences. Chunk starts = file start and the two onsets after the 0.4 s / 0.3 s pauses.
    raw:      start            sil 20 ms   first10 -18.7 dB  later -13.5 dB  delta  -5.2 dB
              chunk 2 (pause)  sil 980 ms  first10 -20.3    later  -4.9     delta -15.5
              chunk 3 (pause)  sil 720 ms  first10 -20.3    later -13.6     delta  -6.8
    mastered: start            sil 20 ms   first10 -27.9     later -15.3     delta -12.6
              chunk 2 (pause)  sil 920 ms  first10 -26.9     later -13.2     delta -13.6
              chunk 3 (pause)  sil 880 ms  first10 -21.2     later -14.8     delta  -6.4
Other onsets inside sentences show deltas of -5 to -25 dB (normal consonant ramp-up). Same measurement on the mastered Hebrew he_basic.wav: start sil 105 ms delta -2.9 dB; post-pause chunk starts delta -18.9, -14.4, -11.7 dB.
Conclusion: the FILE START is abrupt in both languages (only 20-105 ms of silence, first 10 ms within 3-5 dB of the later level in the raw/Hebrew cases). Post-pause chunk starts are ramped (about 7-15 dB below the level 50-100 ms later) but the third English chunk (-6.8 / -6.4 dB) is only mildly ramped. So the trimmed-start symptom is plausible at the beginning of the file and, less strongly, at some chunk starts; mastering does not remove it. A per-chunk analysis from the library's own chunk boundaries would be more reliable than this heuristic.
